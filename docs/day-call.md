# 오늘 장 방향 판정 (day call, #572)

평일마다 오늘 국장(KOSPI)과 미장(S&P 500)의 **시가 → 종가** 방향을 5단계 확률로 판정하고, 장이 끝나면 채점한다.
확률은 숫자 모델에서만 나온다. LLM 은 쓰지 않는다.

- 코드: `backend/desk/day_call.py`(특징 · 추론 · 채점, 순수 파이썬)와 `backend/desk/day_call_train.py`(학습 · 백테스트, numpy, 로컬에서만 돌린다)
- 커밋하는 결과물: `backend/desk/data/day_call/model_<kr|us>.json`(서버가 읽는 모델)과 `report_<kr|us>.json`(검증 숫자)
- API 계약: [#572 이슈 댓글](https://github.com/shindonggeun/trading-desk/issues/572#issuecomment-6966479748)

## 단계

`z = (종가 − 시가) / ATR14`. ATR 은 판정 전날까지의 일봉으로 구한 Wilder 14일 값이다(최근 120봉으로 계산).

| 단계 | key | 조건 |
|---|---|---|
| 강한 롱 | `strong_long` | z > 1 |
| 약한 롱 | `weak_long` | 0.3 < z ≤ 1 |
| 약보합 | `flat` | −0.3 ≤ z ≤ 0.3 |
| 약한 숏 | `weak_short` | −1 ≤ z < −0.3 |
| 강한 숏 | `strong_short` | z < −1 |

- 지수: KR 은 `^KS11`, US 는 `^GSPC` 다(NQ 선물 일봉은 시가가 18:00 ET 라 "개장"이 아니다).
- 리포트에는 경계를 ±0.25 · ±0.75 로 바꾼 결과도 같이 싣는다.

## 회차와 누수 규칙

판정 시각(cutoff)에 **세션이 끝난 봉만** 읽는다(`day_call.cut`). 봉의 종료 시각은 거래소 현지 마감이다.

| 심볼 | 끝나는 시각 |
|---|---|
| ^KS11 | 15:30 KST |
| ^GSPC · ^IXIC | 16:00 ET |
| ^VIX | 16:15 ET |
| ^TNX · DX-Y.NYB | 17:00 ET |
| KRW=X | 런던 자정 봉 + 24시간 |

| 시장 · 회차 | 판정 시각 | 더 읽는 것 |
|---|---|---|
| KR 1차 | 07:30 KST | 코스피 전날까지 · 미국은 전날 밤 세션(05~06 시 KST 마감) · 원/달러는 그 전날 봉 |
| KR 2차 | 09:30 KST | 위 + 오늘 시가 갭 |
| US 1차 | 09:00 ET | S&P 전날까지 · 같은 날 코스피 종가(01:30~02:30 ET 마감) |
| US 2차 | 10:00 ET | 위 + 오늘 시가 갭 |

- "첫 30분 수익률"과 ES 야간 움직임은 야후 분봉이 60일(5 · 15 · 30분봉)과 730일(60분봉, 09:00~10:00 봉이라 09:30 을 넘는다)밖에 없다. 그래서 v1 모델에는 넣지 않는다.
- 과거 기록이 없는 값(KIS 야간선물 · 선물 수급 · VKOSPI · 커뮤니티 · 어닝콜)은 응답의 `context` 에만 싣고 확률에는 넣지 않는다.
- 수능처럼 10시에 여는 날은 KR 2차 시각(09:30)에 시가가 아직 없다. 백테스트는 일봉 시가를 쓰므로 이런 날(1년에 하루 안팎)은 시가를 미리 보는 셈이다. 운영(PR-B)에서는 첫 봉이 나온 뒤에만 판정한다.

## 특징

| 묶음 | 특징 |
|---|---|
| 공통(대상 지수) | 전일 등락 · 5일 · 20일 흐름(ATR 단위), 20일선 이격, 전일 시가→종가, 5일/20일 실현변동성 비, ATR 수준, VIX 수준 · 변화, 미 10년물 금리 변화, 만기일, 월요일 |
| KR | 전날 밤 S&P500 · 나스닥 등락(각 ATR 단위), 원/달러 변화 |
| US | 같은 날 코스피 등락, 달러인덱스 변화 |
| 2차 | 오늘 시가 갭(ATR 단위) |

투자자별 수급(flow-history)은 서버에만 있다. GDELT 뉴스 톤은 이 PC 에 기록이 거의 없다. 그래서 두 묶음은 이번 백테스트에 넣지 않았다(`report.not_run`).

## 모델

- 위치-척도 순서형 로지스틱이다.
  - `μ = β0 + β·x`, `s = exp(γ0 + γ·x)`, `P(z ≤ e) = logistic((e − μ)/s)` 를 고정 경계 ±0.3 · ±1 에서 읽는다.
  - `β` 는 방향(롱 · 숏)을, `γ` 는 크게 움직일지(강한 단계 쪽)를 정한다.
- 학습 구간의 단계 빈도(기후 확률)와 섞는다: `p = (1−λ)·p_model + λ·p_기후`.
- 학습은 표준화한 특징에 L2 를 걸고, 0 에서 시작해 Adam 1500 번(float64)을 돈다. 같은 봉이면 같은 계수가 나온다.
- L2 와 λ 는 학습 구간 안의 확장 창 폴드(마지막 3년을 1년씩)에서 Brier 가 가장 낮은 값으로 고른다. 최근 90일(검증)은 고르는 데 한 번도 쓰지 않는다.
- 서버는 학습하지 않는다. 커밋된 모델을 순수 파이썬으로 읽는다.
- 커밋하는 모델은 검증 구간 **전**까지로 학습한 것이다. 그래서 검증 90일을 PR-B 에서 정직한 백필로 채울 수 있다.


`report.code` 는 `day_call.py` · `day_call_train.py` 의 지문이다. 코드를 바꾸면 다시 만든다.

## 지표

| 지표 | 정의 |
|---|---|
| 방향 적중 | P(롱 두 단계) ≥ P(숏 두 단계) 면 롱. 실제 방향은 시가→종가 부호다(0 은 뺀다). 95% 구간을 같이 적는다. |
| 단계 적중 | 확률이 가장 큰 단계가 실제 단계와 같은 비율 |
| Brier | 5단계 (p − 정답)² 의 합(0~2, 낮을수록 좋다). `brier_skill = 1 − Brier / 기후 Brier` |
| 보정 표 | 5단계 확률을 모두 모아 10% 구간마다 평균 확률과 실제 비율을 비교한다 |
| 기준선 | 항상 롱, 전날 따라가기(전날 시가→종가 부호), 기후 확률(Brier 비교) |

검증 63세션이면 방향 적중률의 표준오차가 약 ±6%p 다. 55% 는 우연과 구분되지 않는다.
