# 화면 디자인 기준 (#96)

혼자 쓰는 매매 데스크다. 화면의 주인공은 **숫자**(가격 · 등락 · 타점)이고, 나머지는 그 숫자를 빨리 읽게 돕는 데서 멈춘다.
토큰은 `frontend/src/styles.css` 맨 위 `:root` 한곳에 있다. 새 화면은 이 토큰만 쓴다.

## 색 — 뜻으로만

| 토큰 | 뜻 |
|------|----|
| `--up` · `--long` | 오름 · 롱 · 매수 · 이익 · 목표 (국내 관례: 빨강) |
| `--down` · `--short` | 내림 · 숏 · 매도 · 손실 · 손절 (파랑) |
| `--ok` | 완료 · 연결됨 (상태 점) |
| `--warn` | 주의 · 진행 중 |
| `--danger` | 오류 — 오름 빨강과 헷갈리지 않게 주황빛 |
| `--sr-support` · `--sr-resistance` | 지지 · 저항 (오름/내림과 겹치지 않는 청록 · 보라) |
| `--accent` | 링크 · 진입선. 색이 아니라 밝기로 구분한다 |

- 장식용 강조색은 없다. 파란 버튼 · 파란 테두리로 "선택됨"을 표시하지 않는다.
- 선택된 것은 한 단계 밝은 면(`--surface-3`), 누를 수 있는 글자는 밑줄로 표시한다.
- 다크가 기본이고 라이트는 `prefers-color-scheme` 로 따라간다. 차트는 같은 토큰을 `getComputedStyle` 로 읽는다.

## 글꼴 · 숫자

- Pretendard Variable 하나(번들, `pretendard` npm — 외부 CDN 없음).
- 크기 단계는 `--fs-xs 11` · `--fs-s 12` · `--fs-m 14`(본문) · `--fs-l 16` · `--fs-xl 20` · `--fs-2xl 28`.
- 가격 · 수량 · 비율은 `font-variant-numeric: tabular-nums`(`.num`).
- 모두 대문자 라벨 · 자간 벌린 라벨을 쓰지 않는다.

## 모양

- 카드 모서리 `--radius 8`, 버튼 · 입력 · 세그먼트 `--radius-s 5`, 작은 태그 3. 알약 모양(999px)은 쓰지 않는다.
- 토글 묶음(`.chips` / `.chip`)은 세그먼트로 그린다. 붙은 버튼 줄이고, 고른 것만 밝은 면이다.
- 상태(`.pill-on` · `.pill-warn` · `.pill-bad`, `.status`)는 테두리 없이 **점 + 글자색**으로 표시한다. 그냥 `.pill` 은 점 없는 작은 글자다.
- 고른 세그먼트는 밝은 면 + 굵은 글자 + 안쪽 선. 면 색만으로 구분하지 않는다.
- "계획과 일치 / 반대" 같은 일치 여부는 방향색(빨강 · 파랑)이 아니라 `--ok` · `--warn` 으로 표시한다.
- 주 버튼은 밝은 면에 어두운 글자로, 화면마다 하나만 둔다. 보조 버튼은 `.secondary`, 글자 버튼은 `.link` 다.
- 그림자 · 그라디언트 장식은 쓰지 않는다. 떠 있는 메뉴(검색 결과 · 툴팁)만 그림자를 쓴다.
- 움직임은 사용자가 한 일에 대한 답(열림 · 깜빡임 갱신)만 넣는다. `prefers-reduced-motion` 이면 끈다.
- 키보드 포커스는 `:focus-visible` 2px 테두리로 언제나 보인다.
