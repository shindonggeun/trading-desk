# 기능 메뉴와 연결 위치 (#923)

메뉴는 기능을 여는 목적에 따라 나눈다. 기존 주소는 같은 화면을 계속 열며 하위 메뉴만 새 그룹에서 찾을 수 있다.
알림과 차트 링크가 전달한 경로 및 쿼리는 각 화면이 계속 해석한다.

| 목적 | 현재 메뉴 및 진입점 | 이전·통합 동선 |
| --- | --- | --- |
| 대시보드 | 대시보드 `#/` | 기존 대시보드와 배치·즐겨찾기 유지 |
| 시장 | 실시간 시세 `#/live`, 선물 시세 `#/futures`, 섹터 `#/sectors`, 주간 지도 `#/weekly`, 반감기 사이클 `#/halving`, 시장 일정 `#/calendar` | 시세판의 이름을 실시간 시세로 명확히 하고 독립 캘린더를 시장 일정으로 이동 |
| 시장 | 수급·포지셔닝 `#/?flow=intraday&view=flow` | 기존 대시보드 시장 수급을 펼친다. 공매도·옵션·펀딩비는 기존 수급 탭을 사용한다 |
| 분석 | 분석 기록 `#/history`, 백테스트 `#/backtest`, 매매 팁 `#/tips`, 기관 포트폴리오 `#/funds`, 리포트 `#/reports`, 아침 시황 `#/briefs/morning` | 분석 기록과 평가 기능을 모은다. 알림으로 열던 아침 시황에 메뉴 진입점 추가 |
| 차트 | 차트 `#/charts` | 시장 아래의 차트 메뉴를 독립 진입점으로 이동 |
| 운영 | 매매 복기 `#/review`, 모의 투자 `#/paper`, 오늘 방향 기록 `#/day-call`, 설정 `#/settings` | 분석 아래의 복기·모의·기록을 운영으로 이동. 머리글 설정 바로가기도 유지 |

`#/market` 알림은 기존과 같이 `#/?flow=intraday`로 바뀌고 대시보드의 수급 카드에서 오늘 장중을 연 뒤
`#/`로 정리된다. 메뉴의 수급 주소는 새로고침과 북마크에서 같은 하위 메뉴를 다시 열 수 있도록 유지된다.
`#/charts?t=…&iv=…` 작동 방식과 `#/chart/<티커>?run=…&interval=…&read=…`의 종목·분석·주기·읽기
컨텍스트는 그대로 이어진다. `#/runs/<ID>`와 `#/reports/<ID>`는 각각 분석 기록과 리포트에 속하며
상세 주소를 유지한다. 설정의 해시 쿼리, 채팅의 기존 경로·위젯, 작은 창의 독립 경로도 같은 화면을 연다.

## 후속 화면의 연결 위치

| 이슈 | 상태와 다음 연결 |
| --- | --- |
| #913 펀딩비 | 기존 시장 → 수급·포지셔닝의 바이낸스 펀딩비 탭을 사용한다. 별도 최상위 메뉴가 필요하지 않다. |
| #915 주봉 신호 | 차트 → 나스닥100 선물의 주봉 보기와 해당 신호 설정이 합쳐지면 연결한다. 종목 차트 주소가 진입점이다. |
| #917·#918 국내·미국 수급 현황판 | 후속 화면이 준비되면 시장의 수급·포지셔닝 항목에서 연결한다. 대시보드 수급 주소와 알림 별칭은 기존 링크가 계속 작동하도록 유지한다. |
| #922 관심군 모니터 | 시장 → 시장 모니터 `#/market-watchboard`에서 연다. 실시간 시세 다음 항목이며 일봉 링크를 기존 차트로 전달한다. |
| #929·#930 종목별 선 알림 | 운영 → 설정의 기존 선 알림 영역에 연결한다. 차트 및 기존 알림의 주소를 재사용한다. |

화면 상단 도움말은 현재 메뉴의 용도와 결과가 해석되는 범위를 요약한다. 자세한 도움말은
호버·키보드 포커스·터치로 열고 Escape로 닫을 수 있다. 기존 화면 안내 투어는 머리글에서 별도로 실행한다.
차트 메뉴에서 용도를 안내하고, 직접 연 종목 차트에는 기존 전체화면 동선을 적용한다.
