# NQ=F 주봉 과매도 겹침 (#914)

## #915 화면 계약

`GET /api/nq/weekly-oversold?weeks=52`는 기존 세션이 필요하다. 표시 기간은 1~104주이며
Yahoo의 NQ=F 주봉 최대 120개를 사용한다. 조회한 원천을 사용할 수 없으면 관측 상태에 표시한다.
응답은 `private, no-store`이다.

| 응답 | 화면에 표시할 내용 |
| --- | --- |
| `method_version`, `settings`, `revision`, `can_edit` | 계산 방식 버전, 현재 규칙과 저장 버전, 소유자 편집 가능 여부. |
| `current` | `matched`(확정 충족), `not_matched`(확정 미충족), `pending`(확정 대기), `unavailable`(판정 불가). `reason`으로 자료 부족·지연·원천 등의 사유를 표시한다. `forming_week`은 진행 주를 따로 표시한다. |
| `current.week`, `evidence` | 뉴욕 월요일 거래주, UTC 마감·확정 기준·조회 시각, 원천. RSI 실제값과 기준을 포함한다. 가격 근거는 `bollinger`, `channel`, `fib`의 지지 수준·판정 상태·실제 저가·종가·허용 범위다. |
| `markers[]`, `study` | 현재 규칙으로 조회 시 재계산한 과거 충족 주와 4주·12주 결과. `edge`는 직전 주가 유효 미충족이었음을 나타낸다. 표시 범위 및 표본 수를 함께 표시한다. |
| `channels[]`, `deliveries[]` | 소유자에게만 텔레그램의 연결 가능 상태와 최근 발송 결과·시도 횟수·다음 재시도 시각을 제공한다. `needs_reconnect`는 응답 형태를 지키려고 남긴 필드로 늘 `false`다(#986). 다른 세션에는 빈 배열을 반환한다. |

`PUT /api/nq/weekly-oversold/settings`는 소유자만 사용할 수 있다. 전체 설정을 저장하고
`settings`와 `revision`을 반환한다. 다음 예시는 초기값이다.

```json
{"enabled":false,"rsi_limit":30,"price_conditions":["bollinger","channel","fib"],"min_hits":1}
```

Wilder RSI(14)의 상한은 0~100이며, 가격 조건은 중복 없이 하나 이상 선택한다. `min_hits`는
선택 수 이하 양의 정수다. 같은 값으로 저장하면 버전을 유지한다. 규칙 활성화나 조건 변경은
새 버전의 기준 상태를 초기화한다. 소스 결측·불일치가 있어 가능한 충족 여부를 결정할 수 없으면
`unavailable`을 반환한다.

## 확정 주와 운영 관찰

#908의 확정 방식에 따라 뉴욕 금요일 17시 마감, 다음 일요일 CME 개장 이후 추출된 원천,
그리고 다음 주봉 라벨을 확인한다. 진행 주는 계산과 발송에 사용하지 않는다. #896의 채널·
볼린저·피보나치 근거를 사용하며 각 지지 기준과 ATR은 신호 주 이전 봉에서 계산한다. 확인된
연속 선물 롤오버 정보가 없어 응답에 불확실성을 표시한다. Yahoo NQ=F의 값은 참고 차트 NQ1!
및 개별 만기와 차이가 날 수 있다.

collector/all에서만, 알림이 켜진 규칙을 기존 #580의 `nq_alert`와 `tone_warning`
수신 설정으로 평가한다. 같은 규칙 버전에서 인접한 두 확정 주가 유효 미충족→충족으로 바뀌고
확정 기준부터 24시간 안에 관측될 때만 텔레그램 원장을 만든다. 최초 관측, 설정 변경,
관측 공백 뒤 첫 주, 소급 수정은 기준 상태만 잡는다. 결측만으로 다시 알림을 받을 수 있게
전환하지 않는다.

데이터베이스의 채널별 발송 키에 현재 소유자·정책 범위, 규칙 버전, 거래주를 포함한다.
#986에서 걷어 낸 채널의 행은 남아 있어도 조회·발송에서 빠진다.
성공한 채널은 다시 보내지 않는다. 명시적인 429 응답은 채널별로 응답 한도를 지키며 최대 세
시도까지 재시도한다. 외부 수신 결과를 알 수 없는 타임아웃·5xx·발송 중 재시작은 `unknown`으로
두고 자동 재발송을 중지한다. 보호 모드에서는 현재 소유자 세대에 들어 있는 승인 수신처만
사용한다. 운영 기본 팩토리에 등록된 승인 수신처는 없다. 이후 승인 수신처를 연결할 때 결과가
불명확한 실제 알림을 수신처 내부에서 재발송하지 않는 계약을 확인해야 한다.

## 4주·12주 관찰 범위

`edge=true`인 표식만 집계한다. 신호 종가 대비 정확히 N주 후 종가의 수익률과 이후 N주
저가 중 최대 추가 하락을 같은 기준으로 계산한다. 기간을 채운 표본과 자료 부족으로
미검증인 표본을 각 기간에 표시하며 최대 추가 하락 15% 이상 사례도 따로 센다.
`study.coverage.unverified_weeks`는 실제로 훑은 원천 범위 안에서 판정하지 못한 주의 수다.
원천 범위 밖인 주는 요청 기간과 실제 조사 기간의 차이로 구분한다.
진행 봉은 연구의 후속 가격에도 쓰지 않는다.

구현 검증은 합성 주봉과 가짜 채널에서 수행했다. [과거 NQ 주봉 표본 검증](nq-weekly-history.md)은
실제 가격 보관본 재연산과 합성 결과를 구분한다. 당시 공급 시각과 롤오버는 확인되지 않았다.
텔레그램의 실제 수신과 첫 실신호는 운영 인계 대상이다.

합성 표본은 2025-01-06~2026-03-02의 확정 61주를 사용했다. 유효 전환 표본은 2건이고
4주와 12주에서 각각 2건을 관찰했다. 두 기간 모두 최대 추가 하락 15% 이상 사례 1건을
집계했다. 합성 기준일을 전환 직후로 옮긴 회귀에서는 후속 기간을 미검증으로 남겼다.
